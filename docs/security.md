**security@example.com**
请包含：
1. 漏洞描述
2. 复现步骤（如适用）
3. 潜在影响
4. 建议修复（如有）
我们将：
- 在 24 小时内确认收到
- 提供定期进展更新
- 适当时给予信用（如您愿意）
- 共同修复漏洞

## 安全最佳实践
### 使用本库时
1. **始终使用最新版本**
   ```bash
   go get -u github.com/vistone/fingerprint@latest
   ```
2. **验证指纹**
   - 使用 AnomalyDetector 检查异常
   - 使用 ContradictionDetector 验证一致性
   - 结合其他信号进行验证
3. **安全存储**
   - 不要硬编码指纹
   - 使用环境变量存储敏感数据
   - 如需要，加密存储的指纹
4. **速率限制**
   - 在指纹端点实现速率限制
   - 监控可疑指纹模式
   - 异常时记录和告警
## 已知限制
1. **指纹伪造** - 如果攻击者有库访问权限，可以伪造指纹
2. **浏览器更新** - 浏览器更新后指纹会改变
3. **TLS 1.3** - 降低指纹的独特性
